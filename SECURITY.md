# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately via repository security reporting
or direct maintainer contact. Do **not** open a public issue with exploit details.

- EN: Include reproduction steps and impact.
- TR: Yeniden üretim adımlarını ve etki bilgisini ekleyin.

## Scope

Security reports should focus on:
- command execution and shell integration paths,
- plugin loading and untrusted input handling,
- configuration and file access boundaries.
